# Extract Labs — Holo theme

Shopify Online Store 2.0 theme for extractlab.com.au, built by DXD Media.

Connect in Shopify admin: Online Store → Themes → Add theme → Connect from GitHub → choose this repo and the `main` branch.

- Assign the `story` template to the Our Story page and `contact` to the Contact page.
- Free-shipping threshold, bundle quantity and social links are under Theme settings.
